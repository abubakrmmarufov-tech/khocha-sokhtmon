# CRM продаж «Хоча сохтмон»

Отдельный сайт для отдела продаж: цены квартир, клиенты, продажи и брони, первый взнос,
рассрочка с процентами, график платежей, поступления и долги. Языки: русский и таджикский
(переключатель, тот же, что на 3D-сайте). Проданная квартира сразу становится красной на 3D-сайте,
забронированная — жёлтой.

Адрес: **https://nurovvv.github.io/khocha-sokhtmon/crm/** (собирается и публикуется вместе с 3D-сайтом).

## Что умеет

| Раздел | |
|---|---|
| Шахматка | все 72 квартиры по этажам: свободна / бронь / продана / не в продаже, цена или покупатель, отметка о просрочке. Нажатие — карточка квартиры с планировкой, ценой и сделкой |
| Продажа и бронь | новый или известный клиент, № и дата договора, скидка, оплата: полностью, рассрочка (равные платежи, убывающие платежи или наценка) или ипотека банка; график считается сразу. Бронь — с датой окончания и задатком; бронь потом оформляется в продажу, задаток засчитывается |
| Сделка | цена, оплачено, остаток, просрочено, следующий платёж, график с отметками, все платежи; внести платёж, печать графика для подписи, изменить условия, расторгнуть (с возвратом денег) |
| Сводка | продано квартир и м², сумма договоров, получено, ожидается, просрочено, средняя цена м²; продажи и поступления по месяцам; платежи на 30 дней, должники, брони |
| Сделки, Платежи, Клиенты | списки с поиском и фильтрами, выгрузка в Excel |
| Цены | цена за м² или своя цена каждой квартиры; сразу на несколько этажей и типов квартир; повышение на % |
| Калькулятор | рассрочка или кредит: ежемесячный платёж, проценты, график; можно сразу оформить продажу |
| Настройки | продавец, валюта (сомони / доллар), сотрудники и роли, выгрузки, резервная копия |

Роли: **менеджер** — сделки, клиенты, платежи; **администратор** — ещё цены, удаление, исправление
платежей, сотрудники и настройки. Это проверяет сама база данных, не только интерфейс.

## Демо и настоящая база

Пока база данных не подключена, CRM работает как **демо**: данные (с примером продаж) хранятся только
в этом браузере, и 3D-сайт показывает проданные квартиры тоже только в этом браузере. Для работы
отдела продаж нужна база данных — бесплатный проект Supabase:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (регион Frankfurt).
2. **SQL Editor** → вставьте [`supabase/schema.sql`](supabase/schema.sql) → в конце файла впишите свою
   почту администратора вместо `admin@example.com` → **Run**. (Файл можно скачать и из CRM: Настройки.)
3. **Authentication → Users → Add user**: вход (почта + пароль) себе и каждому сотруднику.
   **Authentication → Sign In / Providers**: выключите «Allow new users to sign up».
   Сотрудника с его ролью добавьте в CRM: Настройки → Сотрудники.
4. **Project Settings → API**: Project URL и publishable (anon) key впишите в `src/config.js`
   (`SALES`) — и опубликуйте сайт. Ключ публичный по замыслу: без входа по нему видны только статусы
   квартир (функция `flat_status()`), без цен и имён.

Бесплатный проект Supabase засыпает после недели без запросов; пока отдел продаж работает в CRM, а
посетители открывают 3D-сайт, этого не случится.

## Как устроено

- `src/` — страница CRM без фреймворков, как и 3D-сайт; квартиры (номера, площади, планировки)
  берутся из модели сайта (`../src/data.js`), так что номера совпадают.
- `src/calc.js` — график платежей и разнесение платежей по нему; `src/db.js` — данные (Supabase или
  демо); `src/views/` — разделы.
- `supabase/schema.sql` — таблицы, права, `flat_status()` для 3D-сайта; список квартир в нём
  пишет `node crm/supabase/flats.mjs` (после изменения планировок).
- 3D-сайт читает статусы в `../src/sales.js` раз в минуту.

```bash
npm run dev:crm                       # http://localhost:5194/
node tools/crm_check.mjs              # проверка CRM в Chrome (демо): все разделы на RU/TJ, продажа, платёж, бронь
npm run build && npx vite preview --port 5192
node tools/sales_check.mjs            # 3D-сайт с продажами из CRM: красные и жёлтые квартиры
npm install --no-save @electric-sql/pglite && node crm/supabase/test.mjs   # права базы данных (Postgres в памяти)
```
