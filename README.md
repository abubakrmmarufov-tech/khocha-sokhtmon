# Хоча сохтмон — 3D-сайт жилого дома

Интерактивный 3D-сайт жилого дома ЧДММ «Хоча сохтмон» (Душанбе) для продажи квартир. Сделан студией
Jomi Studio. Покупатель крутит дом, выбирает этаж, открывает его в разрезе с мебелью, смотрит
планировку квартиры и гуляет по ней внутри. Языки: русский и таджикский (переключатель в шапке).
Проданные квартиры показаны на здании красным, забронированные — жёлтым (из CRM продаж); цен на
сайте нет.

**CRM продаж** — отдельный сайт для отдела продаж ([`crm/`](crm/README.md),
https://nurovvv.github.io/khocha-sokhtmon/crm/): цены, клиенты, продажи и брони, рассрочка с
процентами, графики платежей, поступления и долги.

## Что в модели

| | |
|---|---|
| Этажи 1–2 | магазины: мраморные пилоны и витрины под выступом верхних этажей, терраса с лестницей, под ней цоколь с приямком |
| Этажи 3–10 | 72 квартиры, по 9 на этаже (типовой этаж с эскиза архитектора) |
| 10 этаж | угловые террасы с перголами, кустами и балюстрадами |
| Кровля | аттик, балюстрады с вазами, выход на кровлю |
| Вокруг | бульвар с парковкой перед домом, двор с парковкой и фонтаном, сады, улицы, город |

Откуда что взято:

- **Планировки** (`src/model/plans.json`) прочитаны из PDF-эскиза типового этажа скриптом
  `tools/plan/extract.py`: стены, окна, комнаты, квартиры, сантехника. Площади и число комнат
  совпадают с подписями на листе. Лист нарисован зеркально к визуализациям — модель следует
  визуализациям.
- **Фасады** сняты с визуализаций заказчика: камера каждой визуализации восстановлена
  (`tools/calib.py`, `tools/cams.json`), модель сравнивается с визуализацией через ту же камеру
  (`tools/cmp_all.sh`). Размеры дома — по эскизу (34 × 21,5 м) и планам 1–2 этажей.
- Исходные визуализации и PDF архитектора в репозиторий не входят (папка `materials/`).

## Запуск

```bash
npm install
npm run dev
```

## Модель

Дом и окружение строятся в Blender 5.2 скриптами `blender/` и выгружаются в веб:

```bash
blender/export.sh
```

→ `public/models/house.glb`, `src/model/complex.json`. После выгрузки модель упаковывается для веба
(`node tools/pack_model.mjs`: UV-координаты округляются до 1/64 м, файл становится на треть меньше).
Проверки сайта в Chrome: `node tools/check_app.mjs`.

Каждый push в `main` собирает сайт вместе с CRM и выкладывает его на GitHub Pages
(`.github/workflows/deploy.yml`). Сторонние текстуры и лицензии — в `ASSETS.md`.

## Графика

Два уровня (`src/quality.js`): **высокий** на компьютерах и **лёгкий** на телефонах (кнопка в углу,
`?quality=low|high`). Что делает картинку реалистичной:

- **Мягкие тени солнца** (`src/shadows.js`, высокий уровень): тень размывается тем сильнее, чем дальше
  от неё то, что её отбрасывает — тень карниза с десятого этажа мягкая, тень подоконника на стене
  резкая, как в жизни. `?shadows=pcf` — штатный фильтр three.js для сравнения.
- **Блум и виньетка** (`src/post.js`, высокий уровень): белая штукатурка на солнце и фонари ночью чуть
  светятся в окружение, как на фотографии; углы кадра темнее на несколько процентов. `?bloom=0`,
  `?vignette=0` выключают.
- **Небо** (`src/world.js`): свечение дымки вокруг солнца и вдоль горизонта с его стороны
  (`?glow=0` выключает). На лёгком уровне небо рисуется один раз в кубическую карту, а не каждым
  пикселем каждого кадра.
- **Ветер** (`src/props.js`): кроны деревьев и пальм слегка качаются (`?still` замораживает — для
  скриншотов и сравнений с визуализациями).
- Стёкла и вода не отбрасывают тень, но всё остальное в той же сетке — отбрасывает (раньше участок
  целиком — газоны, бордюры, скамейки, фонари — оставался без теней).

## Телефоны и медленный интернет

- Модель упакована до 2,6 МБ (`tools/pack_model.mjs`), небо для освещения на лёгком уровне —
  `sky_256.hdr` (130 КБ вместо 1,4 МБ; освещает так же, оно всё равно размывается).
- Если кадры идут медленнее ~28 в секунду, сайт сам снижает плотность пикселей, а на лёгком уровне
  затем уменьшает карту теней (`src/main.js`, `watchFrames`).
- Замеры: `npm run build && npx vite preview --port 4173 & node tools/perf.mjs` (загрузка и частота
  кадров на компьютере, в лёгком режиме и в эмуляции телефона, локально и через 4G).
